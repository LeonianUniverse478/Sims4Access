TS4 Access - speech pack
==========================================

This pack contains Prism 0.18.2 and its licences. Prism connects the mod
to NVDA and other supported screen readers.
No separate NVDA controller DLL is needed.

Extract this zip into your Mods folder, the same way as the mod itself.

Without this pack the mod still talks, using a Windows voice. Your own
screen reader's voice, and braille displays, need the pack installed.

Close the game before updating. Start your screen reader before the game.
Before each play session and after every Sims 4 patch, run the TS4 Access
Helper with the game closed. Choose Enable Script Mods and wait for
confirmation; this checks and enables both Custom Content and Mods and
Script Mods Allowed. Download the tool from the mod's download page.
If a patch resets the settings on the first launch, close the game, run
the helper again, and restart.

If you start NVDA later, narration detects it on a subsequent utterance;
a11y.reload also checks immediately. a11y.status identifies the reader.

Prism 0.18.2 is unmodified. Source:
https://github.com/ethindp/prism/tree/v0.18.2
