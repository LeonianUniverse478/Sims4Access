# Player README restructure

## What changed

Reorganized and rewrote the player-facing `README.txt` to make installation, setup, keyboard controls, and gameplay features easier to find and follow. The revision groups related instructions into clear sections and distinguishes documented features from limitations or areas still needing verification.

## Why

The previous README was difficult to navigate as a step-by-step player guide. This revision is intended to help players find the instructions they need without searching through unrelated material.

## Testing

This is a documentation-only change. The wording draws on hands-on use of the mod and a review of the existing project documentation. Not every feature was tested; in particular, parts of Create a Sim and household management remain unverified. No code was changed, and the build was not run.
