# Live groups and guided catalog placement

The Live scanner starts with Yourself, Sims and Objects. The Accessibility
menu groups current actions, places, Simology, relationships and lot tools.
Existing pack readers, business and event actions remain reachable there.

In Build, select a catalog object and use Guided placement in Ctrl+Alt+H
or Alt+B. The floor picker uses the active lot. The next picker uses the
existing named-room scan and samples other lot areas. After the player
accepts a location, the existing transaction confirms release of the
native Build tool, tries several anchors and orientations, checks room
membership and charges only after placement. Surface items use a free
compatible slot. The Accessibility menu offers refund and undo. The
manual cursor and native placement tools remain available.

## Test steps for Sims 4 1.129.39.1030

- Browse Yourself, Sims and Objects, open and dismiss a Sim interaction.
- Open the Accessibility menu and find Places, Inventory and Now.
- Buy a floor object in a named room and undo the purchase.
- Try a crowded room, a surface object, an outdoor area and an upper floor.
- Cancel both pickers and verify the manual Build cursor still works.
