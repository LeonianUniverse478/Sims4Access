# Identify incoming callers

With keyboard accessibility enabled, an incoming call with a known caller starts with that Sim's name. The implementation adds a localized line to a copy of the outgoing phone dialog, so the name is part of the displayed text as well as the announcement. Unresolved callers retain the game's original message.

The phone fixtures cover caller selection, preservation of dialog data, disabled accessibility and repeated hook installation. In game, accept and decline calls from known Sims and check the name, body and response choices.
