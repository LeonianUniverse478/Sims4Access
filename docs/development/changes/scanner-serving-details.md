# Announce serving details in the object scanner

Food entries report the remaining servings and the quality star count when the corresponding game data is available. When a localized catalog name contains all three Polish quantity variants, the scanner reads the standalone name. Other localization requests keep their original text.

The scanner tree fixtures cover serving statistics, missing data and quantity variants. To verify in game, scan a platter before and after taking a serving, then scan an ordinary object. In Polish, also check a dish whose catalog entry contains several grammatical forms.
