## V9.1 correction and retest

Source inspection found a null previous scope passed to
`DisplayObjectContainer.contains` through `A11yIsInside` during ownership
changes. The surrounding handler catches that error after recording the new
owner but before `A11yFocusInto`, so the next frame does not retry entry.
`A11yIsInside` now returns false if either argument is null.

V9.1 changes only this null guard and its explanatory comment. The original
source is preserved in `build/source-before-v9_1/TooltipManager_patched.as`;
the diff is `build/v9_1-source.diff`. The existing 130 offline checks passed.
The same 24 main and six compatibility movies passed the 61/19 comparisons.
Artifact verification passed and V9.1 was installed at approximately 18:08
local time. The cfg was preserved; V9 rollback files are in
`build/deployed-before-v9_1`. Evidence: `build/v9_1-verification.json`,
`build/v9_1-deployment.json`, `flash/chain-keyboard-v9_1-final.log` and
`flash/gate-compat-v9_1.log`.
