# TS4 Access: Controls & Settings

This guide covers the everyday controls for **TS4 Access**. If you have not installed the mod yet, start with [**Installation & Getting Started**]({{SETUP_POST_URL}}). Object placement has its own [**Build Mode Guide**]({{BUILD_POST_URL}}).

**You can have the controls read aloud in-game!** Press **Ctrl + Alt + H** and choose **Keyboard shortcuts** from the accessibility menu.

## **World Scanner**

Turn **Scanner mode** on in the mod's settings, or press **Ctrl + Alt + Space**. Keyboard navigation and the scanner feature must also be enabled. Scanner mode starts off by default.

Wait until you hear **"Scanner"**, then use these keys **without holding Ctrl or Alt**:

- **Up / Down:** Previous or next item in the current list. Hold the key to keep browsing.
- **Right:** Enter a category or subcategory. On an individual item, repeat its description.
- **Left / Backspace:** Go back one level.
- **Enter:** Enter a category or open a Sim or object's interactions.
- **Space:** Repeat speech.

Your place is remembered when you return to a category. The scanner updates when you switch Sims and hides objects that have no interactions for the active Sim. Objects with unavailable interactions can remain listed so you can open their menu and hear the requirements.

Some checks happen in the background, so a newly found object may appear briefly before the scanner filters it. Press **Ctrl + Alt + S** to refresh. **Ctrl + Alt + W** reads your location.

In Live Mode, the camera follows your active Sim and the arrows do not pan the camera. Scanner mode does not change the Build Mode camera. **Escape closes menus; it does not turn Scanner mode off.**

## **Menus, Dialogs & Panels**

When a menu opens, its controls take over from the scanner. The scanner resumes when the menu closes.

**Simplified menus are enabled by default.** Up and Down move through supported options one at a time, including choices displayed in several columns. Create a Sim and Stories keep their existing controls.

- **Tab / Shift + Tab:** Next or previous control. From the world, Tab begins browsing the game's interface controls.
- **Arrow keys:** Navigate controls or adjust values. Hold a key to keep moving.
- **Enter:** Activate the focused control or confirm a choice.
- **Space:** Select or toggle a choice.
- **Escape:** Go back, close, or cancel.
- **Backspace:** Return from a picker footer button to its item list.
- **Ctrl + Alt + R:** Read the current control or stop speech.

In a text field, the arrow keys edit the text. Use **Tab** or **Shift + Tab** to leave the field.

### **Cooking & Drinks**

Use the arrows to choose a recipe, then press **Enter**. If it opens serving sizes, press **Down** to browse the sizes and **Enter** to choose one. If the game is paused, resume it so your Sim can start preparing the food or drink.

Unavailable recipes remain readable so you can hear requirements such as a missing appliance or ingredient.

### **Shopping & Delivery**

In purchase lists, including **Zoomers Food Delivery**, **Left** and **Right** change the quantity of the focused item. Press **Right** to add one, then continue browsing if you want other items.

**Enter on an item moves to Done; another Enter confirms the purchase.** Tab also reaches Done. Check the total, including any delivery fee, before confirming.

Pizza delivery uses a recipe list instead: focus the pizza you want and press **Enter**.

### **Choosing Sims**

For a single choice, Enter confirms an available row when Simplified menus is on. For multiple choices, use **Space** to select or clear a row, then choose **Done**. The game still applies its selection limits and other requirements.

### **Splitting or Merging Households**

Use **Space** to select a Sim, then choose **Transfer Sim(s)** to move the selection to the other household.

To transfer funds, navigate to the amount field, press **Enter** to edit it, use **Ctrl + A** to select the current number, and enter the new amount. Tab leaves the field. Choose the appropriate **Transfer Funds** button, then **Done** to confirm the household changes. Escape cancels the dialog.

## **Quick Access**

Close text fields before using these shortcuts. Most actions also require closing menus. **Day and time** can be read while a menu is open. The phone shortcut works from the call alert or HUD panels; close dialogs and pickers first.

- **Ctrl + Alt + H:** Open the accessibility menu.
- **Ctrl + Shift + N:** Read needs.
- **Ctrl + Alt + M:** Milestones of the active Sim, by category (Growing Together).
- **Ctrl + Alt + K:** Character values of the active Sim (Parenthood).
- **Ctrl + Alt + V:** Running events. Press Enter on one to send all guests home and end it, end it, or send all guests home. Your household is never sent away.
- **Ctrl + Alt + L:** Turn diagnostic logging on or off (the TS4_Access.log file next to the mod).
- **Ctrl + Alt + C:** Read the current day and time, including when the game is paused, then your household funds.
- **Ctrl + Alt + E:** Read the mood and its description, then every moodlet with its effect, time left, reason and description, all at once.
- **Ctrl + Alt + G:** Read wants and fears.
- **Ctrl + Alt + Q:** Open the action queue. Each row is something the active Sim is doing or waiting to do, with who chose it. Enter cancels that action.
- **Ctrl + Alt + P:** Open a waiting call or text. With Simplified menus on and nothing waiting, open the phone action list.
- **Ctrl + Alt + 1 through 8:** Switch to a household Sim.
- **M:** Open travel.

In the Sim's inventory, pressing Enter on an item opens an item menu: Item actions opens the game's usual menu, and the sell rows sell one, sell a whole stack after asking first, or open the game's sell window to choose how many.

The accessibility menu also gives you access to skills, career, inventory, relationships, calendar, day and time, household funds, known contacts, and other information.

The **Businesses** row reads every business your household owns, including mod businesses such as the WickedWhims strip club: open or closed, star rating, business funds, today's items sold, customers, revenue, costs and net profit, markup, and employees with their hourly wages. Press Enter on one to open the game's business panel.

With **Growing Together**, the **Milestones** row lists your Sim's milestone categories. Press Enter on one to hear each milestone, whether and at what age it was reached, and the game's description or hint. With **Parenthood**, the **Character values** row reads each value on its scale, the trait it leads to at age up, and its description.

With menus closed in Live Mode, **Shift + Tab** toggles first-person view. Inside a menu or panel, it moves to the previous control instead. The scanner still works in first-person view, and its camera follow resumes when you leave that view.

## **Phone & Travel**

With Simplified menus on, open **Phone** from the accessibility menu or use **Ctrl + Alt + P** when no call or text is waiting. Choose a category, then an action. **Back to the phone** returns to the categories; Escape closes the list.

For travel, leave **Travel list** and **Keyboard** enabled in Settings. Press **M**, choose **Go alone** or **Choose who comes**, then choose a world and destination. Some buildings offer an additional list of units.

Travel from the phone goes directly to the destination lists. **To choose companions, use M and Choose who comes.** If the game is paused, resume it after making your choices so the Sim can travel.

**Back to worlds** and **Back to places** return to the previous lists. Escape cancels the trip. **Open the map instead** continues using the game's map; some destinations require this.

Vacation travel uses the same setting. Read the stay length and price before confirming a rental.

## **Optional Numpad Controls**

Enable **Numpad navigation** in Settings and turn **Num Lock** on. These keys navigate menus and panels, rather than the world scanner:

- **Numpad 4:** Previous control.
- **Numpad 6:** Next control.
- **Numpad 5:** Activate.
- **Numpad 8:** Read the current control or stop speech.
- **Numpad Period:** Back or close.

Additional scanner shortcuts and the read-only Live Mode lot grid are listed in the included **CONTROLS.txt**.

## **Speech Modes**

The mod includes four speech modes:

- **Hover:** Reads supported controls and interface elements automatically as you hover over them.
- **Manual:** Waits for you to use the read shortcut for captured interface text.
- **Beeps:** Uses short audio cues for automatic interface announcements.
- **Off:** Disables automatic narration and its audio cues.

These modes control automatic narration. Some explicitly requested announcements, such as command feedback, can still speak. Choose the speech mode from the accessibility settings or in the configuration file.

If speech is coming through NVDA, JAWS, or another supported screen reader, that reader controls its voice and speed. **The mod's voice settings only affect the fallback Windows voice.**

## **Changing Settings**

Press **Ctrl + Alt + H** and open **Settings**. This is where you can change options such as Scanner mode, Simplified menus, Build controls, speech mode, verbosity, and braille output. Verbosity is Full by default, which says what a thing is before its name (Category, Subcategory, Dialog, Menu open); Brief says only the names.

**Simplified menus and Build controls start on. Scanner mode starts off.** You can turn Simplified menus off if you prefer the original menu navigation. Sim action announcements are also enabled by default.

For additional options, open **TS4_Access.cfg** next to the mod files in Notepad. The file is generated by the mod; it is not included in the download. Save your changes, then restart the game or open the cheat console with **Ctrl + Shift + C**, enter **`a11y.reload`**, and press Enter. Close the console before navigating menus again.

The included **CHEATS.txt** lists optional settings and help commands. You do not need to use these commands for normal gameplay.
