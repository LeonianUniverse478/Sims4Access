# TS4 Access

*Screen Reader is now **TS4 Access**! This expanded release is a joint project with **LeonianUniverse**, bringing more accessibility features and keyboard support to The Sims 4.*

**TS4 Access** is a joint project by **tyjokr and LeonianUniverse**. It adds narration, keyboard navigation, and accessible gameplay menus to *The Sims 4*, providing support for blind and visually impaired players that is not available in an unmodded game.

The mod reads **menus, panels, dialogs, pie menus, tooltips, and notifications aloud**, and can also **announce what your Sim is doing**. You can find Sims and objects, open their interactions, and furnish your home using the keyboard!

Narration begins at the **main menu**, with keyboard support for loading saves, choosing a home, and selecting a season if you have **Seasons** installed. Live Mode and object placement in Build Mode are also supported. Some parts of the game still require the mouse; please see the limitations below.

## **Accessibility Features**

- **World Scanner:** Browse Sims and objects by category, hear their names and locations, and open their interactions. The scanner updates for your active Sim and filters out objects with no interactions.
- **Accessibility Menu:** Check needs, mood, skills, career, inventory, relationships, and more. You can also open the phone, switch household Sims, change settings, and have the keyboard shortcuts read aloud.
- **Simplified Menus:** Use the arrow keys to move through supported options one at a time, including phone actions and gameplay dialogs for jobs, events, food, and drinks. This is **enabled by default**.
- **Travel & Moving:** Choose travel destinations from lists of worlds and places. When choosing a home, hear whether a lot is occupied and whether your household can afford it.
- **Build Mode:** Browse the catalog and place supported objects using a spoken lot cursor. Rotate placed objects, undo a placement, or sell an object at the cursor.

## **Speech & Screen Readers**

**You do not need to have a screen reader installed to use the mod.** The mod can use a Windows text-to-speech voice instead. **Microsoft Zira** is selected by default, but the voice can be changed in Settings.

To use your own screen reader, such as **NVDA or JAWS**, or a braille display, install the free [**Speech Pack**](https://simfileshare.net/folder/274249/) alongside the mod. **Microsoft Narrator is not supported.**

⚠️ **Windows only:** TS4 Access does not currently support macOS or consoles.

## **Installation & Getting Started**

Install the mod directly inside **`Mods\TS4_Access`**, and download the [**TS4 Access Helper**]({{HELPER_DOWNLOAD_URL}}).

**Before each play session and after every game patch, run the TS4 Access Helper with The Sims 4 closed.** Open **TS4AccessHelper.exe**, choose **Enable Script Mods**, and wait for confirmation before starting the game through **Steam** or the **EA app**. The tool checks and enables **both Custom Content and Mods and Script Mods Allowed**, so please make this part of your setup!

Game patches can turn mods off again. Check for a compatible TS4 Access release after a patch. If the game resets the settings on its first launch, close it, run the tool again, and restart.

These guides cover setup and controls in more detail:

- [**Installation & Getting Started**]({{SETUP_POST_URL}}) - Setup, the Speech Pack, the helper, and your first household.
- [**Controls & Settings**]({{CONTROLS_POST_URL}}) - Keyboard shortcuts, the scanner, menus, travel, and speech options.
- [**Build Mode Guide**]({{BUILD_POST_URL}}) - Placing, rotating, and selling objects.

In-game, press **Ctrl + Alt + H** to open the accessibility menu and choose **Keyboard shortcuts** for spoken help. The download also includes **README.txt**, **CONTROLS.txt**, and **CHEATS.txt** for offline reference.

## **Important Limitations**

**Not every part of the game is fully accessible yet.**

- **Create a Sim:** Some controls support keyboard navigation, but many appearance and customization controls still require the mouse.
- **Build Mode:** Walls, floors, roofs, rooms, stairs, pools, terrain, and paint still require the mouse. Objects that need a wall, ceiling, fence, water, or bare ground cannot currently be placed using the mod's cursor.
- **Maps:** Some destinations still require the game's map. After selecting a lot, you may need to continue through the controls to reach **Play** or **Confirm**.

## **Compatibility**

TS4 Access is **Base Game compatible** and does not require any expansion packs.

⚠️ This mod overrides several UI files to enable narration and keyboard navigation, so it may conflict with other mods that modify the user interface.

If you use **weerbesu's UI Cheats Extension**, install the matching [**compatibility add-on**](https://simfileshare.net/folder/274251/) using my [**priority folder guide**](https://www.patreon.com/tyjokr/posts/165980351). **Update the add-on alongside TS4 Access.**
