TS4 ACCESS HELPER
Version 1.1 | Windows

Run this tool before each play session and after every Sims 4 patch to
check that both Custom Content and Mods and Script Mods Allowed are on.

ENABLE SCRIPT MODS
1. Close The Sims 4.
2. Extract this ZIP and open TS4AccessHelper.exe.
3. Choose Enable Script Mods, or simply press Enter.
4. Wait for the confirmation, then open the game from Steam or the EA app.

The helper enables both Custom Content and Mods and Script Mods Allowed.
You can keep it anywhere, such as your Desktop. It needs no installation
and does not download, update or launch the game or your mods.

IF YOUR SIMS FOLDER IS NOT FOUND
Choose Sims folder and select Options.ini. It is normally in:
Documents\Electronic Arts\The Sims 4

Use the folder your game uses, including OneDrive Documents if applicable.
This is your user folder, not the Steam or EA game installation folder.
If there is more than one possible folder, the helper asks you to choose.
If you have never run The Sims 4, open it once and exit to create Options.ini.

KEYBOARD CONTROLS
Enter or Alt+E: Enable Script Mods.
Tab / Shift+Tab: Move between the button and the folder link.
Alt+F: Choose Sims folder.
Escape or Alt+F4: Close the helper.
Completion and errors appear in standard Windows dialogs your screen reader
can read. Press Enter to dismiss them.

AFTER GAME UPDATES
Check for compatible versions of your mods before re-enabling them.
Run the helper after every game patch, with The Sims 4 closed, and choose
Enable Script Mods before playing.
If the game turns mods off on the first launch after an update, close it,
run this helper again, and restart the game.

BACKUPS
The helper enables all installed mods and preserves your other settings.
Before changing Options.ini, it saves the original in TS4 Access Backups
inside your Sims user folder. Saves and GameVersion.txt are left alone.
No new backup is made when both options are already enabled.
To restore: close the game, copy the desired backup into the Sims user
folder, and rename that copy Options.ini, replacing the current file.
