TS4 ACCESS UPDATER
Version 1.0 | Windows

The updater installs the latest TS4 Access test build from GitHub:
https://github.com/LeonianUniverse478/Sims4Access/releases

USING IT
1. Close The Sims 4.
2. Open TS4AccessUpdater.exe and press Enter (Check for updates and install).
3. Wait for the message that says the build is installed, then press Enter.
4. Open the game from Steam or the EA app.

Run it again whenever you are told there is a new build. If you already have
the latest build, it says so and asks whether to install it again.

WHAT IT DOES
- Downloads the latest release and checks it against its published
  checksum. A damaged or changed download is not installed.
- Backs up your current TS4 Access files to TS4 Access Backups in your
  Sims folder, then installs the new ones where the mod already is (or in
  Mods\TS4_Access the first time). If it finds a second copy of the mod,
  it moves that copy to the backup, so the game loads only one.
- Installs the speech pack if you do not have it, or refreshes it.
- Turns on Custom Content and Mods and Script Mods, as the TS4 Access
  Helper does.
It does not change your saves, other mods or anything else.

KEYBOARD
Enter or Alt+C: Check for updates and install.
Tab / Shift+Tab: Move between the button and the folder link.
Alt+F: Choose Sims folder (pick Options.ini in your Sims 4 user folder).
Escape or Alt+F4: Close the updater.
Results and errors appear in standard Windows dialogs your screen reader
can read. Press Enter to dismiss them.
