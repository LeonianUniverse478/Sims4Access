Read START-HERE.md, docs/development/BUILD-AND-TEST.md, GFX-SAFETY.md, ARCHITECTURE.md and EXCHANGE.md before making changes. They describe this kit's current workflow. ## Boundaries

- This directory is Leo's development copy. Never edit a sibling project, the game installation, or a live Mods folder as part of a build.
- Ask Leo before installing or driving the game. Stop screen input if he takes control. Never replace/delete mod files while TS4_x64.exe or TS4_DX9_x64.exe runs. Use an existing backed-up test save, not a full CAS run unless that feature specifically requires it.
- The source is public under the MIT licence, with tyjokr's agreement (2026-10-14): https://github.com/LeonianUniverse478/Sims4Access, branch dev. Third-party and game inputs keep their original rights and are never committed or published: EA's interface movies (flash/work-*/gfx) and UI Cheats Extension's movies (flash/uicheats-base/*.swf) are made locally with Dev.ps1 setup. Publish player releases only when Leo asks.
- Do not change runtime behavior just to make an offline test pass. Reproduce the failure, explain stale expectations where applicable, add relevant regression coverage, and distinguish offline checks from live evidence.
- Preserve `.handoff`, `reference`, baseline EA movies, and UI Cheats bases. They identify what tyjokr supplied. Ask for a rebase if they no longer match the installed game; never remove hash checks to force a build.
- Do not run `compile.py` directly or historical deploy/build variants. Use Dev.ps1. `compile.build` is reused as a library, with safe staging and path stripping around it.
- Keep dev.local.json private. Do not return personal logs, saves, settings, credentials or third-party installers. Logs may contain Sim names; send only relevant redacted excerpts when asked.

## Implementation expectations

- Python game calls run on the simulation-thread pump, not the Windows keyboard-hook thread. Keep hooks fast and game APIs off background threads.
- Input belongs to the active dialog/picker/text field before the world scanner. Respect AltGr, focus loss, key-up, held-key state, opening-key fences, and queued-action state checks.
- `modal` means navigation ownership, not always a blocking dialog. The phone guard now has a separate blocking bit. Do not revert that distinction. Preserve both startup socket and loaded-zone command transports when adding messages.
- Do not remove the bundled ctypes source. The game's Python is trimmed; a module installed on your desktop may not exist in-game. Check imports against the game's archives.
- Edit only canonical `flash/TooltipManager_patched.as` and `flash/extra-classes/*.as` for UI behavior. Generated per-movie templates/exports are disposable. Read the GFX guide before adding any movie or changing integer operations.
- Keep Prism DLL names and the existing discovery locations intact (`_prism_path` in `Scripts/tyjokr_a11y_speech.py` checks `TS4_Access_SpeechPack\prism.dll` beside the mod, `prism.dll` beside the mod, then `TS4_Access_SpeechPack\prism.dll` at the Mods root; there is no recursive search). The project supports Windows TTS without a speech pack. Retain the complete Prism license/notice set whenever distributing its DLL.
- Settings are generated by the mod; player ZIPs do not ship a cfg. Logging and scanner mode default off; build controls and simplified menus default on. Preserve existing player choices. Captions are absent from generated player cfgs.
- Use current player credits: tyjokr and LeonianUniverse. Do not mass-rename historical/internal module names that carry compatibility behavior.

## Completion evidence

Record the exact source changes, the commands run and exit codes, the JSON test report's `passed` and `input_stable` values, both fidelity-gate outcomes for UI changes, and the package SHA256 values. A test count alone is not a passing result. State game version, screen reader/voice, save context, and observed results for live cases. Do not describe a candidate as released or live-verified without that evidence.

End each work round by using `Dev.ps1 return` with a clear summary and honest testing notes. Tell Leo which ZIP to send. Never reset the baseline mid-round. Tyjokr will review and integrate changes on his side.
