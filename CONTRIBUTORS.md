# TS4 Access contributors

Everyone whose work is in TS4 Access. Accepted pull requests are added here.

- **tyjokr**: creator of TS4 Access.
- **LeonianUniverse**: lead developer since November 2026; guided new game, the updater,
  pack readers, businesses, Build mode cursor and keys, and the other changes
  in the changelog.
- **Michael Maslo**: TS4 Access Plus (Alt-key readouts, reminders, Sim creation
  without Create a Sim, the Build helper).
- **DaRainbowGirlXX**: Build cursor and scanner additions (scanner range,
  moving furniture, wall and room reading, target layers, room labels,
  experimental surface placement and hanging wall objects); house building,
  roofs, basements, detached buildings, lot planning, chair snapping,
  measured build coordinates, many screen-reader fixes for game screens,
  household actions and the speech helper fix.
- **Ar-Anaviel**: quick cancel with Q and Shift+Q, keeping the action queue
  open after cancelling, servings and native quality in the scanner, storing
  objects in Sim and household inventories, browsing moodlets one by one,
  event goals with V and caller names on incoming calls.
